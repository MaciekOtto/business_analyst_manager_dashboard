# Business Analyst Manager Dashboard

---

## 🇵🇱

### Opis projektu

Interaktywny kokpit menedżerski dla stanowiska **Business Analyst Manager** - osoby odpowiedzialnej za zarządzanie zespołem analityków biznesowych i nadzór nad projektami analitycznymi. Kokpit pozwala w kilka sekund ocenić efektywność zespołu, terminowość projektów, jakość danych oraz zadowolenie interesariuszy, bez przeglądania szczegółowych raportów operacyjnych.

Projekt powstał w ramach studiów. Opiera się na **syntetycznie wygenerowanym zbiorze danych**, który odzwierciedla realistyczne środowisko pracy zespołu analitycznego.

### Potrzeby informacyjne użytkownika

- monitorowanie liczby i statusu projektów,
- kontrola terminowości i średniego czasu realizacji,
- ocena wpływu finansowego projektów,
- obserwacja jakości danych w czasie względem dopuszczalnego progu błędów,
- ocena satysfakcji interesariuszy,
- analiza obciążenia analityków i zapotrzebowania ze strony poszczególnych działów.

### Wskaźniki i wizualizacje

| Wskaźnik | Forma prezentacji | Zakres informacji |
|---|---|---|
| Average Project Duration | Karta KPI | Średni czas realizacji projektu (w dniach) |
| On-Time Project Rate | Karta KPI | Odsetek projektów zakończonych w terminie |
| Financial Impact | Karta KPI | Łączny przychód wygenerowany przez projekty |
| Total Projects | Karta KPI | Liczba projektów w analizowanym okresie |
| Active Projects | Karta KPI | Liczba projektów aktualnie w realizacji |
| Data Quality Errors vs Threshold | Wykres liniowy | Liczba błędów jakości danych a dopuszczalny poziom |
| Projects by Status | Wykres kołowy | Struktura projektów wg statusu (w trakcie / zakończone / opóźnione) |
| Projects by Analyst | Wykres słupkowy poziomy | Rozkład projektów między analitykami |
| Average Stakeholder Satisfaction | Wskaźnik Gauge | Średnia ocena satysfakcji vs wartość docelowa |
| Projects by Department | Wykres kolumnowy | Liczba projektów wg działów organizacji |

### Interaktywność

Kokpit zawiera fragmentatory (slicery) pozwalające filtrować dane według:
**statusu projektu**, **działu**, **analityka** oraz **zakresu dat** (data startu projektu).

### Decyzje biznesowe wspierane przez kokpit

- alokacja zasobów i wyrównywanie obciążenia analityków,
- planowanie nowych projektów i przyszłych zasobów,
- reagowanie na opóźnienia i wzrost liczby błędów jakości danych,
- ocena jakości pracy zespołu z perspektywy interesariuszy.

### Potencjalne źródła danych w rzeczywistej organizacji

Systemy zarządzania projektami (np. Jira, Azure DevOps), systemy ERP (np. SAP) dla danych finansowych, systemy CRM (np. Salesforce) dla danych o interesariuszach, narzędzia do monitorowania jakości danych oraz hurtownie danych.

### Stos technologiczny

- Power BI Desktop (model danych, miary DAX, wizualizacje)
-  Syntetyczny zbiór danych (CSV/Excel)

## English

### Project overview

An interactive management dashboard for a **Business Analyst Manager** - a role responsible for leading a team of business analysts and overseeing analytical projects. The dashboard lets the manager assess team efficiency, project timeliness, data quality and stakeholder satisfaction within seconds, without digging through detailed operational reports.

The project was created as part of my university studies and is based on a **synthetically generated dataset** that mimics a realistic analytics team environment.

### User information needs

- tracking the number and status of projects,
- monitoring on-time delivery and average project duration,
- assessing the financial impact of projects,
- observing data quality over time against an acceptable error threshold,
- evaluating stakeholder satisfaction,
- analysing analyst workload and demand from individual departments.

### Metrics and visualisations

| Metric | Visual | Description |
|---|---|---|
| Average Project Duration | KPI card | Average project duration (days) |
| On-Time Project Rate | KPI card | Share of projects completed on schedule |
| Financial Impact | KPI card | Total revenue generated by projects |
| Total Projects | KPI card | Number of projects in the analysed period |
| Active Projects | KPI card | Number of projects currently in progress |
| Data Quality Errors vs Threshold | Line chart | Detected data quality errors vs acceptable level |
| Projects by Status | Pie chart | Project structure by status (in progress / completed / delayed) |
| Projects by Analyst | Horizontal bar chart | Project distribution across analysts |
| Average Stakeholder Satisfaction | Gauge | Average satisfaction score vs target |
| Projects by Department | Column chart | Number of projects per department |

### Interactivity

Slicers allow filtering by **project status**, **department**, **analyst** and **date range** (project start date).

### Decisions supported

- resource allocation and workload balancing,
- planning new projects and future capacity,
- reacting to delays and rising data quality errors,
- assessing team performance from the stakeholder perspective.

### Potential real-world data sources

Project management tools (e.g. Jira, Azure DevOps), ERP systems (e.g. SAP) for financial data, CRM systems (e.g. Salesforce) for stakeholder data, data quality monitoring tools and data warehouses.

### Tech stack

- Power BI Desktop (data model, DAX measures, visuals)
- Synthetic dataset (CSV/Excel)
